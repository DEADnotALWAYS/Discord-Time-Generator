# Privacy Policy

Discord Timestamp Generator does not collect, store, or transmit any personal or non-personal user data.

## Data Collection
This extension does not collect any user data.

## Data Usage
All functionality runs locally in the user's browser. No information is sent to external servers.

## Permissions
The clipboardWrite permission is used only to copy the generated timestamp when the user clicks the Copy button.

## Third Parties
This extension does not use third-party services, analytics, or external scripts.
